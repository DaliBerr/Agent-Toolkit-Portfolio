# 执行规格：让 Agent 按规格实现玩法系统

《苍灵志》的刷怪、敌人 AI 和房间生成三个系统，都是先写执行规格，再交给实现 Agent 去做。这里收录敌人 AI 的规格和对应的实现日志，原样复制自游戏仓库。

## 规则

- **规格内容**：写明当前仓库事实、目标与边界、核心接口、分阶段实施步骤、验收标准、风险应对和验证命令。
- **规格冻结**：冻结后，实现 Agent 不得修改规格，也不能另起目标文档，只能更新实现日志。
- **遇到冲突**：如果发现规格有缺陷、与仓库事实冲突，或者验收条件无法执行，实现 Agent 必须停下，把问题写进日志的 Blockers 区域，由我裁决。
- **阶段记录**：每完成一个阶段，日志都要记下改动的文件、运行的验证命令、结果和剩余风险。

## 结果

- **小兵**：六类小兵（Swarm、Ranged、Chaser、Dasher、Tank、Control）已按规格接入 2D 状态机。
- **精英**：四类精英完成了第一版。
- **阻塞**：实现期间 Blockers 为空。
- **未完成**：日志最后一次更新是 2026-07-07，当时手动 Play 调参还没有完成。
