# Lilith Document Boundaries

- `AGENTS.md`：每次必须遵守的硬边界与按任务入口；不复制完整操作协议。
- `README.md`：短架构和专题导航；实现参数、算法、验证细项进仓库 Docs，只维护一个当前主源。
- 共享 Project/TODO：导航、未验收风险与下一步；不累计测试数量、Git 状态或任务流水。
- 共享 `Knowledge/Troubleshooting/Lilith/`：已证实的根因、防复发原则、当前专题链接；症状索引直达文件/标题。失效原型和实验过程进 Archive。
- repo `memory.md`：短离线指针，不复制排障正文或项目状态。
- Codex 内置记忆：日常偏好、最近工作和历史线索；不手工改它的生成文件，不作为当前实现、硬规则或操作授权。
- 只有真实交接需要才写 Handoff；普通任务不写 Session，也不同时刷新所有看板。历史默认不读；追溯时明确路径与问题。

新安全风险、可复用根因或正式入口变化更新对应主源及必要指针。源码/专题证据不足时标明待验证，不把静态检查写成人工验收。维护细则按需读共享 Memory_Rules。
