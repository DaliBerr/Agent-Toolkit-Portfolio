# 离线数值实验：DemoBalanceLab

这是《苍灵志》Demo 的离线数值实验室。代码和实验报告在私有的游戏仓库里，这里只收录方案概述。实验室由 Agent 编写；目标、可调范围和关键取舍由我确认。

## 要达到的体验

- 玩家完成两章，共 13 个战斗房和 2 个章节 Boss。
- 有同类游戏经验的玩家，通常在第 3–4 次尝试时通关。
- 一次成功流程的活跃时间约 15 分钟。

离线实验不代替玩家测试，它只负责四件事：

1. 检查数值有没有明显的矛盾或漏洞。
2. 判断目标在允许的调参范围内能不能达到。
3. 从大量合法组合里筛出少量值得人工测试的候选。
4. 说明每个候选为什么更好，还有哪些风险。

实验得到的通关率都只是“合成玩家”的代理结果。没有真实玩家数据，就不能把它当成真实通关率。

## 一次模拟

每次模拟按正式游戏的顺序走完一整趟：

1. 开局选择。
2. 战斗房：敌人按开场、主战、高潮三段释放。
3. 奖励与法术书配装。
4. 第二章商店。
5. 章节 Boss。
6. 失败后结算，购买永久升级。

失败后重新开始，最多尝试四次。

合成玩家有五类策略：协同规划、爆发速清、控制续航、触发召唤和即时收益。所有候选使用同一批随机种子，方便公平比较。

模拟不还原逐帧物理、真实瞄准和操作疲劳，所以最终候选必须经过人工游玩。

## 哪些数值能动

每项数值只能属于下面一种状态：

| 状态 | 含义 |
| --- | --- |
| 自动调整 | 搜索器可以在边界内修改 |
| 人工审批 | 可以生成提案，但不能自动采用 |
| 锁定 | 本轮禁止修改 |
| 模拟校准 | 只用来描述合成玩家，不能写回游戏 |
| 派生值 | 由其他数值计算得出，不直接调整 |

以下内容锁定，不允许搜索器修改：

- 房间数量和精英房位置；
- 法术组件的语法类型和槽位结构；
- 敌人、组件、配方和 Boss 招式的增删。

## 流程

1. **冻结输入**：正式数值、实验规则、随机种子、调参边界和模拟版本都固定下来。任何一项变了，都要新建实验。
2. **检查与基线**：先做正确性检查，再用当前正式数值跑出基线。
3. **可达性检查**：如果目标在现有边界内达不到，就停下来交给设计决定，不自动扩大边界。
4. **分阶段搜索**：每个阶段只开放少量相关的控制项，并保护前面阶段已经达到的目标。
5. **联合微调与重评**：对最敏感的几个控制项做联合微调，再在同一批种子上重新比较。
6. **验证与留出测试**：先做验证，再做一次性的留出测试。
7. **人工审批**：候选只写入隔离目录，不会自动修改正式数值或 Unity 资产。人工批准后，才在 Unity 里试运行并做内部游玩。

长时间运行时有两条约束：

- **不占满电脑**：搜索在后台以低优先级运行，保留两个逻辑核心给桌面。
- **按证据续跑**：每 120 分钟检查一次证据，默认停止；只有确实还在改善时才继续下一个窗口。

方案和实现都由两个不同模型的 Agent 交叉审阅。
